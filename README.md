# Groww, First Investment mode

Case-study prototype for the Groww PS-II Product Intern case (Sept 2026). Not affiliated with Groww.

A first-timer path inside Groww's existing shell (Stocks, F&O, Mutual Funds, Pay): documents during onboarding, three basics cards, then one income-linked rule ("keep ₹X untouched, invest Y% of anything above that"), reviewed in rupees before it is set. Stocks and F&O stay open behind a one-screen risk note. "Ask before you invest" is scripted, no live model and no free-text input.

Static app, no build step: open index.html or the GitHub Pages link. Hidden test route: #/evals (23 automated checks).
